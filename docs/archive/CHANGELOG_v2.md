# Changelog

## v2.140.0

### 版本号合并整理

- 版本号收敛为单一来源 `app/__init__.py::__version__`：FastAPI `version`、Web 模板静态资源版本均派生自它；`pyproject.toml` 同步并由回归测试锁定。

- 新增 CLI `ofbot2 version` 显示框架版本；README / dev_guide 命令清单同步；版本一致性测试扩展到 CHANGELOG 顶部条目。

## v2.139.0

## v2.138.0

### 版本号整理与内置功能深化

- 版本号单一来源：新增 `app/__init__.py::__version__`，FastAPI `version` 与 Web 模板静态资源版本（`?v=`）统一引用它，消除此前 `base.html` 静态版本长期停留在 2.118.0 的滞后；新增版本一致性回归测试（`app.__version__` 与 `pyproject.toml` 同步）。

## v2.137.0

### 助手职责归并（可维护性）

## v2.136.0

### 文件中心批量下载

- 文件中心新增「批量下载」：勾选多个文件后打包 zip 下载（`POST /files/bulk-download`，与导出中心批量下载一致，含路径安全校验与 `files.bulk_downloaded` 审计）；未选择文件时给出明确提示。

## v2.135.0

### 账户页错误反馈修复

- 修复密码修改失败后账户页从不显示原因的问题：此前模板读取路由传入的固定 `error: None`，`?error=1/2` 跳转无任何反馈；现改为读取查询参数，「当前密码不正确」与「新密码至少 6 位」分别展示（其他错误原样显示）。

## v2.134.0

### Webhook 历史一键重放

- Webhook 历史记录页每条记录新增「重放」按钮（`POST /webhooks/{name}/history/{id}/replay`）：用真实载荷再次触发该 Webhook，便于调试自动化链路；载荷与过滤器匹配则提示“已重放并触发流程”，不匹配则提示“未触发流程”，并写入 `webhook.replayed` 审计。
- 配套回归测试覆盖匹配/不匹配两种重放场景。

## v2.133.0

### 命令解析深化

- 激活此前定义但从未使用的 `basic.command_sep` 配置：命令解析支持参数分隔符（默认 `.`），如 `/ping.x` 解析为命令 `ping`、参数 `x`（`/ping.x y` → 参数 `x y`），与空格参数并存。
- 配置页「基础配置」新增命令参数分隔符输入（逗号分隔），保存后即时生效（启动与保存均同步到命令注册表）。

## v2.132.0
