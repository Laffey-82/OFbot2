# 3 分钟上手

三步让机器人跑起来并开始服务你的群。

## ① 连接机器人（约 1 分钟）

1. 安装并登录一个协议端，推荐 **NapCat**（NTQQ 无头端）。
2. 在 NapCat 开启「反向 WebSocket」，地址填 `ws://127.0.0.1:8080/onebot/v11/ws`。
3. 打开 Web 后台 →「连接中心」，确认 `napcat_main` 状态为「已连接」。

其它接入方式（Chronocat / Lagrange / Mirai / 官方机器人）见 [CONNECTIONS.md](CONNECTIONS.md)。

## ② 安装插件（约 1 分钟）

1. 打开 Web 后台 →「插件市场」。
2. 浏览或搜索插件（如 `dice` 掷骰子、`keyword_reply` 关键词回复、`signin` 签到、`todo` 待办）。
3. 点击「安装」（二次确认），安装后插件**默认未启用**。

也可用命令行：`py -m app.cli plugin repo list` / `py -m app.cli plugin repo install dice`。

## ③ 开启功能（约 1 分钟）

1. 打开 Web 后台 →「插件」页，启用刚安装的插件。
2. 打开「监听环境」页，添加你的群号。
3. 在功能开关矩阵中，为该群开启对应功能（如「掷骰子」「入群欢迎」）。

在群里发送 `/help` 查看该群可用的命令；`/help <命令>` 查看用法示例。
