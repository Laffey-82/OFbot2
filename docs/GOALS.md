# OFbot 2 开发目标

## 当前目标

把 OFbot 2 打磨成可以长期运行的成熟机器人框架：

- 插件化架构稳定：插件可加载、卸载、重载且不残留状态；命令/任务/监听全声明式注册。
- 多协议多账号并存：OneBot v11/v12、Red（legacy）、Satori、Mirai、QQ 官方机器人，连接独立启停。
- 监听环境化：每个群/私聊独立控制功能开关、权限、黑名单与账号绑定。
- Web 后台安全可管理：账户、配置、插件、连接、任务、审计、备份。
- 数据持久化到 SQLite，任务与插件任务重启恢复。
- 无已知运行缺陷，测试、静态检查、端到端冒烟全部通过。

## 当前状态

- 已完成监听环境化重构（1.0 正式版）：`/scopes` 三态开关矩阵、作用域策略、声明式 features。
- 多连接架构与 `ConnectionManager` 落地，连接增删/启停即时生效。
- 命令参数与子命令声明式解析（类型/必填/默认/choices），参数错误自动提示用法。
- 已接入审计日志、命令统计、限流、权限、自愈、告警。
- 238 项自动化测试 + ruff + compileall + e2e 冒烟全绿，GitHub CI 持续运行。

## 后续目标

- bubus 事件总线并发加固：消除高并发 pending 事件的库级竞态（替换或自研轻量总线）。
- 插件运行时沙箱：子进程隔离 + 文件/网络白名单，作为可选部署模式。
- Agent 长期记忆：向量检索 + 记录中心持久化，升级为长期助手。
- 浏览器端 E2E：用 Playwright 覆盖 Web 后台关键路径。
