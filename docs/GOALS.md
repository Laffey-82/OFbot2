# OFbot 2 开发目标

## 当前目标

把 OFbot 2 打磨成可以长期运行的成熟机器人框架：

- 插件化架构稳定：插件可加载、卸载、重载且不残留状态；命令/任务/监听全声明式注册。
- 多协议多账号并存：OneBot v11/v12、Red（legacy）、Satori、Mirai、QQ 官方机器人，连接独立启停。
- 监听环境化：每个群/私聊独立控制功能开关、权限、黑名单与账号绑定。
- Web 后台安全可管理：账户、配置、插件、连接、任务、审计、备份。
- 数据持久化到 SQLite，任务与插件任务重启恢复。
- 无已知运行缺陷，测试、静态检查、端到端冒烟全部通过。

## 当前状态（v1.0.8+ 修复批次）

- 已完成监听环境化重构（1.0 正式版）：`/scopes` 三态开关矩阵、作用域策略、声明式 features。
- 多连接架构与 `ConnectionManager` 落地，连接增删/启停即时生效。
- 命令参数与子命令声明式解析（类型/必填/默认/choices），参数错误自动提示用法。
- 已接入审计日志、命令统计、限流、权限、自愈、告警。
- 271 项自动化测试 + ruff + compileall + e2e 冒烟全绿，GitHub CI 持续运行。
- 稳定与运维收尾：数据库引擎/事件总线重置显式释放（测试零警告）、`/tasks` 页面连接泄漏修复、
  日志轮转与历史遗留文件统一清理、`transport.connections` 收敛为唯一配置来源。
- 架构级重构：自研事件总线替换 bubus（删除 `os._exit` 兜底）、插件静态安全审计、
  Playwright 浏览器端 E2E、插件子进程沙箱（可选部署模式）。

## 后续目标（按版本批次）

- v1.1：自研事件总线替换 bubus——高并发 pending 事件优雅排空 + 超时取消，移除 `os._exit` 兜底。
- v1.2：插件安装/`plugin check` 静态安全审计强化（高危调用扫描 + 依赖白名单）与
  Playwright 覆盖 Web 后台关键路径（登录/连接/监听环境/插件/任务/流程）。
- v1.3：插件运行时沙箱——子进程隔离 + 文件/网络白名单，作为第三方插件的可选部署模式。
- 远期：Agent 长期记忆（向量检索 + 记录中心持久化），升级为长期助手。
